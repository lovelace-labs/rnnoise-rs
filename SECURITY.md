# Security Policy

| Version | Supported |
| ------- | --------- |
| 0.x     | :white_check_mark: |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security reports.

Email **security@lovelacelabs.ai** with:

- A description of the vulnerability and the affected component
- Steps to reproduce (or proof-of-concept)
- Impact assessment and any suggested mitigations

You will receive an acknowledgement within 48 hours and regular updates as we
work on a fix. Coordinated disclosure is appreciated; we will credit reporters
in the release notes unless anonymity is requested.

See also the org-wide policy at
<https://github.com/lovelace-labs/.github/blob/main/SECURITY.md>.
